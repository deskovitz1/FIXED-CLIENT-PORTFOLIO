# Second Sight postcards

Drop short H.264 MP4 clips here, then refresh the website. WebM and M4V are also supported; export MOV files as MP4 before adding them.

Clips play muted and loop while visible, using the same player as NEOGENESIS. The first five clips fill the top-left, top-right, center, bottom-left, and bottom-right cells of the 3×3 grid. Remaining cells use unique stills. With fewer than five clips, stills fill the available spaces.

Files are sorted by name. Use prefixes such as `01-`, `02-`, and `03-` to choose their order. All clips, including those beyond the first five, appear throughout the fullscreen gallery. Reduced-motion preferences are respected.
